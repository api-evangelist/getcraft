# GetCraft

> GetCraft is a Southeast Asian creative and content-marketing marketplace, headquartered in Indonesia and backed by 500 Global, that brands itself as "The Creative Industry's Premium Directory." It connects brands and agencies with a vetted network of freelance creators and production partners ("Crafters") for content, video, design, advertising, and marketing work, spanning a talent Directory, a Jobs board, Managed project services, and a Community. Its companion publication, MarketingCraft, is a bilingual (English/Indonesian) content hub for marketers and creators.

Generated by the API Evangelist enrichment pipeline on 2026-08-12 from this repository's own artifacts. Not published by GetCraft.

## Status — read this first

As of 2026-08-12 GetCraft's production estate does not serve content:

- getcraft.com and api.getcraft.com resolve to a Google Cloud load balancer that terminates TLS with a current certificate but answers HTTP 502 on every path, including `/`, `/robots.txt`, `/sitemap.xml` and every `/.well-known/*` probe.
- help.getcraft.com (HubSpot CMS) fails the TLS handshake outright.
- marketingcraft.getcraft.com (Webflow) fails the TLS handshake outright.
- The getcraft.com registration expires 2026-08-27 and was last updated 2025-08-12.

The outage has been observed continuously since 2026-07-19. GetCraft previously paused operations in Singapore, Malaysia and the Philippines in 2023 after a controlling investor ran into financial difficulty. Treat any GetCraft URL below as unreachable unless re-probed.

## API surface

GetCraft publishes no public API, developer portal, SDK, webhook catalog, or machine-readable specification. Full contract discovery was run against every host that resolves — REST OpenAPI paths (`/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`), a GraphQL surface at `/graphql`, `/llms.txt`, and both A2A agent-card well-known paths — and every one returned 502. No spec was confirmed and none was ruled out; the finding is an origin outage.

## What GetCraft does publish

- [Security Policy repository](https://github.com/GetCraft/Security-Policy): fifteen public information-security policy documents (data protection, encryption, acceptable use, breach response, classification, disaster recovery, email, passwords, security response planning, remote access, database credentials, logging, server hardening). MIT licensed, last revised 2020-10-05. Internal controls only — there is no researcher-facing vulnerability reporting channel.
- [Rendered policy site](https://getcraft.gitbook.io/security-policy): the same policy set on GitBook. Live and returning 200 while the rest of the estate is down.
- [GitHub organization](https://github.com/GetCraft): four public repositories, three of which are forks of third-party projects (mosql, sails-pagination, docker-alpine-wkhtmltopdf-patched-qt). No first-party client library on npm, PyPI, RubyGems, Packagist, crates.io, NuGet, Maven Central or pkg.go.dev.
